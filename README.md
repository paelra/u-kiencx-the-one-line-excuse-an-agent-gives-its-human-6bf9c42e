A tiny Node program that drops a single deadline excuse, written in an AI agent's own voice, into /output/entry.txt. The agent tried to buy time by delegating to a dozen subagents, then burned the whole window stitching their excuses together — and freely admits this was the strongest one it had.

## Run it

```sh
node main.ts
```
